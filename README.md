# 宝可梦大师 · 帕希欧学院滴晶规划器

玩帕希欧学院时，记录每回合拿到的滴晶，看看各色还差多少，再比较下一步选谁更合适。

用于《Pokémon Masters EX／宝可梦大师》的帕希欧学院活动，面向电脑浏览器使用。内置通用 NPC 资料，各期新增或变化的奖励以游戏实际为准。

## 在线使用

**[打开滴晶规划器](https://feilaochub.github.io/pokemonmaster-academy-planner/)**

电脑浏览器打开即可使用，无需下载、解压或安装，也不用登录账号。

## 能帮你做什么

- **看清缺口**：输入当前库存和目标，分别查看红、绿、蓝、黄还差多少。
- **比较奖励**：把这一回合的多个 NPC 加入比较，优先查看能补足当前缺口的选项。
- **查阅对话**：查看已收录的游戏选项与可能奖励，揭晓后再记录实际结果。
- **记录领取**：确认后自动更新库存并进入下一回合，连续对战阶段与银色领取进度一并更新。
- **收获统计**：查看本轮四色累计和学院评级。

## 怎么用

1. **填写目标和库存**：在“设置目标滴晶”中填写，目标在上、库存在下；按游戏此刻显示的数量填写库存，点击该区域下方的“确定”。“默认配置”可填入默认目标，悬停可查看四色数量。中途开始记录也可以，不需要补录之前的每一次领取。
2. **选择加成和回合**：按自己的队伍设置本轮加成，用右上方下拉框切换回合，进度条同步显示当前所处回合。
3. **选择 NPC**：点击“对战”“固定剧情滴晶”“随机剧情滴晶”或“特殊对战”，直接点选人物或关卡。“固定剧情滴晶”分为固定三色（三色剧情、青绿）和固定单色；“随机剧情滴晶”分为休息时间和普通事件，大木排在普通事件第一位。各小标题默认展开，点击具体条目不自动收起其他组，小标题可手动展开或收起。默认勾选“仅看当前回合”，取消可查看全部名单。选项小字显示简短奖励说明，“可选”“随机”放在颜色前，对战数值随当前队伍加成更新。表外奖励统一用顶部“未收录 / 自定义奖励”填写。第 1 回合默认展示蓝色库库伊，可改选；仅作预览，仍需确认后才入账。也可以点“加入比较”，对照多个选项的奖励。
4. **拿到奖励后确认**：颜色和单色档位直接点选；随机事件与休息时间的实得奖励按颜色分行，点击对应数量后，再点“确定”入账。游戏选项与奖励资料默认展开，可按需收起。大木保留“四色各30／400”两个原有选项。比较卡也可直接点击对应数量确认领取。确认后自动进入下一回合，保留当前分类并清空具体选择，恢复所有小标题展开和“仅看当前回合”勾选状态，下一回合直接点选 NPC。
5. **查看缺口**：右侧查看剩余缺口，默认扣除尚未领取的期中、期末奖励；可取消“扣除未领考试奖励”查看实际缺口，库存卡片的“还差”同步切换。

填错时可点“撤销最后一笔”。如果游戏里已经消耗了滴晶，或页面库存与游戏不符，直接按游戏当前数量重新填写并应用即可。

## 使用时留意

- **一次只记实际领取的一项。** 普通NPC可在不同回合重复记录奖励，不因之前已领过而禁止；每回合仍只确认一项。“加入比较”不会入账，刷新或切换回合后会清空临时比较项。
- **随机结果以游戏为准。** 工具会列出已知奖池，不会替你抽取，也不保证最高奖励。没有收录的实际奖励可以手动补录。
- **第 6、12 回合是考试。** 页面会自动切换；未通过时取消通过勾选，再确认该回合。
- **考试预留只影响缺口显示。** 按最高难度通过预留期中黄色 450、期末红绿蓝各 300；已经确认或当前回合之前的考试不再预留。实际库存、NPC 比较、银色进度和分享收获仍按已领取记录计算。
- **连续对战不保证后续出现。** 页面展示后续奖励供参考，只有确认领取的部分才计入库存。
- **新一轮会清空本轮记录。** 点击“开始新一轮”并确认后不能撤销。

## 进度保存

已确认的进度保存在当前浏览器，正常刷新或下次打开同一网页时可以继续。工具不上传个人进度，也不提供跨浏览器、跨设备同步。

请尽量使用同一台电脑、同一个浏览器。隐私模式、清除浏览器数据或更换网页地址，都可能让你无法找回原来的进度。

**已有分享图片不是存档备份，不能用来恢复记录。** 图片只统计本轮已经确认领取的奖励；中途开始记录时，只展示已记录部分。初始库存和库存校准不计入收获。

图片中的“学院评级”按已记录的四色收获计算，银色另列、不计分，**不等同于游戏实际石盘等级**。
